## 🌊 About the Project

The **GCEK Naval NCC Portal** is a modern, information-driven web platform developed for the **4 (Odisha) Naval Unit NCC, Government College of Engineering Kalahandi (GCEK), Bhawanipatna**.

The platform aims to establish a digital identity for the unit by bringing its activities, achievements, training updates, cadet resources, and important information together in one place.

More than just a website, it serves as a digital space to celebrate cadet achievements, preserve unit memories, encourage participation, and promote the values of the National Cadet Corps.

## 🎯 Project Objectives

- Establish a dedicated online identity for GCEK Naval NCC.
- Showcase the unit's achievements, camps, events, and activities.
- Provide cadets with easy access to important notices and updates.
- Create a resource hub for SSB and defence career preparation.
- Preserve the unit's journey through photographs and achievements.
- Improve communication and information accessibility for cadets.

- Highlights of cadet accomplishments.

### ⚓ Camps & Activities
- NCC camps and training activities.
- Naval-wing events and participation.

### 📸 Digital Gallery
- Memories from NCC camps and events.
- Training photographs and unit activities.
- A visual record of the unit's journey.

### 🎖️ SSB Preparation Hub
- Defence career guidance.
- SSB preparation resources.
- Recommended learning materials and video resources.

### 🚀 Defence Careers
- Information about defence career opportunities.
- Entry routes and eligibility resources.
- Guidance for aspirants interested in serving the nation.

### 👥 Alumni Section
- A space to highlight former cadets.
- Celebrate the contributions and journeys of alumni.

### ⚙️ Portal Customization
- Custom portal editing interface.
- Manage selected unit information and content.
- Browser-based persistence for supported customizations.

## 🎨 Design Philosophy

The portal follows a premium naval-inspired visual language.

| Design Element | Selection |
|---|---|
| Primary Colour | Deep Navy `#001428` |
| Accent Colour | Naval Gold `#D4AF37` |
| Heading Font | Cinzel |
| Body Font | Plus Jakarta Sans |
| UI Style | Modern Glassmorphism |
| Visual Identity | Naval Crest & Warship-inspired elements |

The interface is designed to reflect discipline, professionalism, leadership, and the spirit of the Naval NCC.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd GCEK-Naval-NCC
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

```text
http://localhost:3000
```
